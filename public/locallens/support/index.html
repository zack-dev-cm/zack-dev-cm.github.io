Compatibility

  • Desktop Chrome 138 or newer.
  • Chrome built-in AI must be available and, on first use, may need a short local model warm-up download.
  • LocalLens works on the active tab only and requires readable page text or a user selection.

Reviewer checklist

  • Open a text-heavy page in Chrome 138+.
  • Click the LocalLens action and run Summarize page.
  • Select text on the page and run Summarize selection, Simplify selection, Translate selection, and Safe-share selection.
  • If Chrome downloads a local model on first use, wait for the progress indicator to finish and repeat the action.

Troubleshooting

No result appearsReload the page, reopen the popup, and confirm the current tab contains readable text.
First-run delayChrome may still be downloading the built-in model locally. Wait for the popup progress state to clear.
Selection actions seem emptyHighlight the text again before reopening the popup so the active selection is still present.
Need helpOpen a public issue with the Chrome version, the page type, and the action you ran.
