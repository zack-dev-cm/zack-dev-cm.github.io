Chrome extension local AI active-tab only

Read faster without shipping your page to somebody else's server.

LocalLens turns the current page or your current selection into a local summary, plainer rewrite, translation, or safe-share brief using Chrome built-in AI. No account, no background crawling, and no persistent host permissions.

What LocalLens does

Summarize the pageTurn dense articles or docs into quick takeaways without leaving the tab.
Simplify selected textRewrite jargon-heavy passages into plainer language on demand.
Translate in placeTranslate only the text you select instead of moving the whole page elsewhere.
Safe-share modeMask obvious sensitive strings before sending the selected text into the local AI flow.

Why it is review-friendly

  • Single purpose: turn active-tab page text into local summaries, rewrites, translations, or safe-share briefs.
  • Minimal permissions: no host permissions, no storage permission, no background scraping.
  • Local-first processing: Chrome built-in AI handles the content inside the browser environment.
  • Clear user action model: nothing runs until the user opens the popup and chooses an action.
