VEHICLE LAB / DOCUMENTATION

Documentation

Vehicle Lab is an experimental engineering notebook that connects project intent, authored geometry, revision decisions and scoped numerical evidence. The vehicle study demonstrates the workflow; a portable project format lets you create your own.

Choose your starting point

  • Getting started: run the site and create a new project.
  • Examples: compare the vehicle notebook, desk rover and replay fixture.
  • Project format: models, stages, revisions, evidence and claims.
  • Geometry integration: import your own OBJ or author a packed mesh adapter.
  • Simulation integration: export and replay your own sampled body states.

What is included

The release includes a static website, interactive 3D studio, project CLI, numerical analysis examples, a recorded vehicle walkthrough, and verification tools. No account, cloud service or network connection is required once the source package and any optional development dependencies are available.

Documentation map

Start with a short tutorial, then use the geometry and simulation guides for integrations. The project reference defines the interfaces. The architecture page explains where CAD, a physics engine and this notebook meet.

Software checks establish software behavior. A rendered assembly or a successful replay does not establish that a physical vehicle fits, carries a load, or can be fabricated and operated.
