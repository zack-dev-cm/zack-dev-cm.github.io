Skill Sprint Clipper
Privacy Reviewer Guide

Support

Skill Sprint Clipper is a local Chrome extension for turning selected or pasted lesson text into a 20-minute proof pack.

Expected Use

  1. Select lesson text on a normal page and choose Create Skill Sprint Pack from the context menu, or paste text into the popup.
  2. Click Generate.
  3. Copy, export, save, or delete the pack locally.

Troubleshooting

  • The extension does not run on Chrome Web Store pages or chrome:// pages.
  • If the context menu is unavailable on a restricted page, use manual paste in the popup.
  • If local history is missing, confirm you are using the same Chrome profile and have not cleared extension data.

Reviewer Checklist

No account, backend, API key, paid service, or Skool login is required. The expected permissions are contextMenus and storage; there are no host permissions.
