Support Reviewer Guide

Privacy Policy

Effective date: 2026-05-06

Skill Sprint Clipper turns text that you explicitly select or paste into a local 20-minute lesson skill pack. The extension is local-first and does not require an account, backend, API key, paid service, or Skool login.

Data Handled

  • Website content limited to text you explicitly select from a page or paste into the popup.
  • User-generated content limited to generated pack fields, edits, exports, and packs you choose to save locally.

The extension does not collect browsing history, tab inventory, cookies, passwords, form fields, messages, private community member lists, payment data, or account credentials.

Storage And Network Behavior

Saved packs are stored locally in Chrome extension storage in your browser profile. Skill Sprint Clipper does not send selected text, pasted text, saved packs, exports, usage events, or settings to a developer server.

The extension has no analytics, ads, hosted sync, remote model calls, remote JavaScript, or remote WebAssembly.

Export And Deletion

You can copy the share note, copy Markdown, export Markdown or JSON, save packs locally, delete individual saved packs, or delete all saved packs.

Chrome Web Store User Data Policy

Use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Selected content and local storage are used only to provide the user-facing local pack builder, copy/export, save, and delete features.

No Ads, Sale, Or Third-Party Transfer

Skill Sprint Clipper does not sell user data, show ads, transfer user data to third parties, use data for unrelated purposes, or use data to determine creditworthiness or lending eligibility.
