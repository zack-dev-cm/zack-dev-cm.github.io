# URL -> Markdown Worker (RapidAPI + Cloudflare)

> Edge worker that streams HTML to Markdown with a RapidAPI gateway and MCP SSE endpoint.

## Summary
Cloudflare Worker monetized through RapidAPI and bundled with an MCP SSE endpoint for agent integrations. Streams Markdown with Google Cache fallback and solid error handling.

## Key Features
- RapidAPI monetization
- Streaming HTML->Markdown
- MCP SSE endpoint
