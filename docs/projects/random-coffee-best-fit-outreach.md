# Random Coffee Best Fit Outreach

> Consent-first matcher for ranking best-fit coffee chats and preparing reviewed LinkedIn or Discord outreach packets.

## Summary
Random Coffee Best Fit Outreach is a public-safe workflow for matching people into useful coffee chats without scraping or auto-sending messages. It scores fit from provided profiles, drafts double opt-in outreach for LinkedIn or Discord, and logs review state so each introduction stays operator-approved.

## Project Link
https://zack-dev-cm.github.io/projects/random-coffee-best-fit-outreach.md

## Key Features
- Ranks best-fit people from provided profiles and project context
- Drafts consent-first LinkedIn or Discord outreach packets for review
- Avoids scraping, selfbots, and automated sending in the public workflow
- Keeps decision logs reproducible for future community or team-matching rounds

## Benchmarks & Analytics
