# GitHub Repo Summarizer (Chrome Extension)

> Privacy-first Chrome extension that summarizes repo structure locally.

## Summary
Fetches GitHub repo trees with the user's token and summarizes structure locally - no external servers involved.

## Project Link
https://zack-dev-cm.github.io/projects/github-repo-summarizer-chrome-extension.md

## Key Features
- Privacy-first (local token usage)
- Automated repository structure summarization

## Tech Stack
- Chrome Extension
- JavaScript
- GitHub API
