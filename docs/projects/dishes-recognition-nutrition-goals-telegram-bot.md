# Dishes Recognition & Nutrition Goals Telegram Bot

> Calorio Telegram bot that recognizes dishes from photos/audio and tracks nutrition goals.

## Summary
Calorio is a multimodal Telegram bot that understands dish photos/voice/text, logs calories/macros, and nudges users toward daily nutrition targets. It also ships a beta Telegram Mini App for profile + diary management and analytics.

## Project Link
https://zack-dev-cm.github.io/projects/dishes-recognition-nutrition-goals-telegram-bot.md

## Key Features
- Vision + voice dish detection
- Nutrition goal tracking
- Telegram-native UX

## Tech Stack
- Telegram Bot API
- OCR
- Speech-to-Text
- LLMs
