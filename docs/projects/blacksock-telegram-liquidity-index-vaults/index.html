Blacksock - Telegram Liquidity & Index Vaults

Telegram mini app for star-factoring, index vaults, and governance in the Telegram economy.

Overview

Mini app + API stack that quotes star-factoring, handles index vault subscribe/redeem flows, and runs governance proposals and votes with optional TON wallet linking.

What It Covers

  • Star-factoring quotes + request lifecycle
  • Index vault subscriptions and NAV tracking
  • Governance proposals + votes
