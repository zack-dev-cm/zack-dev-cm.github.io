# DoctorAI - Dermatology Triage Mini App

> Telegram mini app for dermatology-first AI triage with verification guardrails and an optional therapist mode.

## Summary
FastAPI service with image-aware triage, a verification pass for safety, and a lightweight Telegram Web App UI built for fast patient intake.
