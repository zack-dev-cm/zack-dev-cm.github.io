# Turbo Tots Garage (motion + touch PWA)

> Gentle, goofy dashboard with a turbo gauge, big arrow pads, and a glowing clock for toddlers.

## Summary
Touch-first toddler dashboard with a turbo gauge, glowing clock, motion-sensor boosts, and playful engine/tick sounds.
