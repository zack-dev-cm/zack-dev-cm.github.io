AI Chat Navigator Privacy Policy

Last updated: June 11, 2026

AI Chat Navigator is a Chrome extension for navigating supported AI chat pages, saving reusable prompt snippets, and locally refining draft prompts. This policy applies to extension ID jnoonpeekddinkiecaonhocaflcgbhap.

Local-Only Operation

The extension does not require an external server. Version 4.1.2 stores settings, saved prompts, feedback notes, usage counters, and local error events in chrome.storage.local on the user's device. It does not use chrome.storage.sync, remote analytics endpoints, remote prompt APIs, or remote code.

Data The Extension Handles

  • Supported chat page content may be read in the browser to draw navigation dots and local helper controls.
  • Prompt text is processed locally when the user clicks a prompt improvement or adjustment control.
  • Saved prompts and feedback notes are kept locally only when the user chooses to save them.
  • Local usage and error events are kept on device to support debugging.

Data Sharing

AI Chat Navigator does not sell, transfer, or share user data with third parties. Chat content, prompts, saved snippets, feedback, analytics events, and settings are not sent to the developer's servers.

Permissions

The extension uses activeTab so user-triggered settings changes can apply to the current supported chat tab. It uses storage to save local settings and user-saved snippets. Content scripts run only on the supported AI chat sites listed in the extension manifest.

Retention And Deletion

Local data remains on the user's device until the user clears extension data, resets extension settings, removes saved prompts, or uninstalls the extension. Uninstalling the extension removes its local Chrome extension storage.

Contact

For privacy or support questions, use the support link on the Chrome Web Store listing or open an issue through the public portfolio at zack-dev-cm.github.io.
