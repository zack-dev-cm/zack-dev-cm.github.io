Reviewer Guide

No account, backend, API key, paid service, or Skool login is required.

Fixture Text

Use a short prompt checklist before starting a task. Decide the outcome, timebox the attempt, write one done test, and capture one before/after note.

Smoke Test

  1. Install the submitted package in a clean Chrome profile.
  2. Open any normal page containing the fixture text.
  3. Select only the fixture text.
  4. Right-click and choose Create Skill Sprint Pack.
  5. Confirm the popup page contains only the selected text.
  6. Click Generate.
  7. Confirm a takeaway, action, checklist, done test, blocker question, proof post, and redaction checklist are shown.
  8. Copy or export the pack.
  9. Save the pack locally, then delete it from local history.

Expected Review Readback

  • Manifest V3.
  • Permissions: contextMenus, storage.
  • Host permissions: none.
  • Network service: none required for user content.
  • Remote code: none.
