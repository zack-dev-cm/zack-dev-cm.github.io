# GitHub Repo Summarizer (Chrome Extension)

> Privacy-first Chrome extension that summarizes repo structure locally.

## Summary
Fetches GitHub repo trees with the user's token and summarizes structure locally - no external servers involved.

## Locale update in review
Draft #28 consolidates two earlier popup proposals. It adds English, Arabic, Hebrew and Simplified Chinese captions, right-to-left layouts, readable fallbacks and localized validation while preserving controls and generated source text. Seventeen source fixture tests pass. Actual installed-extension behavior, native locale selection, downloads and clipboard acceptance remain pending; this draft is not the published store version.
