# Aetheria - Ideas-to-Media Engine (alpha)

> Generates short movie scenes with CGI, music direction, and narrated stories.

## Summary
Given a rough idea, Aetheria drafts stories, builds CGI scenes, suggests music, and voices narration to deliver short cinematic clips.

## Project Link
https://zack-dev-cm.github.io/projects/aetheria-ideas-to-media-engine-alpha.md

## Key Features
- Multi-modal media generation
- Creative concept development
- AI-powered CGI

## Tech Stack
- Generative AI
- Text-to-Video
- Text-to-Speech
- LLMs
