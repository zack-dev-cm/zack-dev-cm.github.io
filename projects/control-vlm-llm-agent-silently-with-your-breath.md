# Control VLM-LLM Agent Silently With Your Breath

> Start/stop a neural agent with breathing patterns - no voice commands needed.

## Summary
Breath-based control after a short calibration: detect sharp exhales to start, smooth exhale to stop. Works on mic audio or sniffles for silent agent control.

## Project Link
https://zack-dev-cm.github.io/projects/control-vlm-llm-agent-silently-with-your-breath.md

## Key Features
- Non-verbal AI control
- Pattern recognition of breathing acoustics

## Tech Stack
- Audio processing
- Neural Networks
