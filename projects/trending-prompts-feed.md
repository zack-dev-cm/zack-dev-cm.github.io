# Trending Prompts Feed

> Reddit-style board with trending scores and extension integration.

## Summary
Crowdsourced prompt feed with real-time trending, built on Tornado and integrated with the Navigator extension for prompt suggestions.

## Key Features
- Crowdsourced prompt engineering
- Real-time trending
- Browser extension integration

## Tech Stack
- Tornado
- JavaScript
- Community-driven content
