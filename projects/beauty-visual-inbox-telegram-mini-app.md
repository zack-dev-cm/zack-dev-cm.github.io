# Beauty Visual Inbox - Telegram Mini App

> Telegram mini app + bots for salons: publish photo batches, likes, notifications, and analytics.

## Summary
Admin and client bots manage submissions and broadcasts, while the mini app ships a vertical feed with batch navigation, likes, and engagement stats.

## Project Link
https://zack-dev-cm.github.io/projects/beauty-visual-inbox-telegram-mini-app.md

## Key Features
- Admin + client bot workflows
- Vertical feed with batch navigation
- Likes + notification analytics

## Tech Stack
- React
- TypeScript
- Node.js
- Express
- Prisma
- Postgres
- Telegram Bot API
