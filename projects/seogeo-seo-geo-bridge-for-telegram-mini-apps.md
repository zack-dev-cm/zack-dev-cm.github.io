# seogeo - SEO/GEO Bridge for Telegram Mini Apps

> SSR hub + bridge pages that make Telegram mini apps crawlable and discoverable.

## Summary
Server-rendered hub and per-app bridge pages with OG/Twitter meta, JSON-LD schema, startapp deep links, and attribution tracking for Telegram mini apps.

## Project Link
https://zack-dev-cm.github.io/projects/seogeo-seo-geo-bridge-for-telegram-mini-apps.md

## Key Features
- SSR landing pages with JSON-LD
- startapp deep links + attribution tracking
- Channel directory + LLM-friendly endpoints

## Tech Stack
- TypeScript
- Express
- SSR
- Telegram Web Apps
- Firestore
- JSON-LD
