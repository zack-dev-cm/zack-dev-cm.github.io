# Task Zavod - Micro-Task Marketplace

> VLM-powered micro-task builder with Telegram + web worker flows.

## Summary
Business users define tasks in free-form text; VLMs structure them and auto-approve payouts. Workers use web or Telegram, backed by Tornado + SQLite.

## Project Link
https://zack-dev-cm.github.io/projects/task-zavod-micro-task-marketplace.md

## Key Features
- VLM-powered task structuring
- Automated approval & payout
- Web & Telegram interfaces

## Tech Stack
- Tornado
- SQLite
- OpenAI
- VLM
- Telegram Bot API
