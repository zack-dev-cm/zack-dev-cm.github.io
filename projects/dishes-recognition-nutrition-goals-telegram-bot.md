# Dishes Recognition & Nutrition Goals Telegram Bot

> Telegram bot that recognizes dishes from photos/audio and tracks nutrition goals (1,000+ users).

## Summary
Multimodal Telegram bot that understands dish photos/voice/text, logs calories/macros, and nudges users toward daily nutrition targets.

## Project Link
https://zack-dev-cm.github.io/projects/dishes-recognition-nutrition-goals-telegram-bot.md

## Key Features
- Vision + voice dish detection
- Nutrition goal tracking
- Telegram-native UX

## Tech Stack
- Telegram Bot API
- OCR
- Speech-to-Text
- LLMs
