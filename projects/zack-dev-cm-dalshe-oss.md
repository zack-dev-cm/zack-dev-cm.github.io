# Dalshe - Circular Clothing Pickup Mini App

> Legacy project URL kept for compatibility. Use the canonical project link below.

> Telegram mini app for scheduling clothing donations with courier pickup and status updates.

## Summary
Users submit a short form, couriers collect items, and the bot delivers status updates while admins track pickup requests.
